# 🧮 Web Calculator

A clean, responsive web-based calculator created to practice core frontend development concepts, DOM manipulation, and modern CSS styling.

---

## 🚀 Features

* **Basic Arithmetic:** Addition, subtraction, multiplication, and division.
* **Responsive Design:** Clean, user-friendly layout optimized for both desktop and mobile screens.
* **Interactive UI:** Smooth button interactions and real-time screen updates.

---

## 🛠️ Built With

* **HTML5:** Structure and markup.
* **CSS3:** Custom layout, styling, and animations.
* **JavaScript:** Core mathematical logic and DOM manipulation.

---

## 🎯 Learning Objectives

This practice project was built to strengthen skills in:
* Implementing JavaScript logic for user input handling.
* Structuring interactive web elements cleanly.
* Styling UI components using modern CSS techniques.
